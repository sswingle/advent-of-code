This repository contains my solutions to [Advent of Code](https://adventofcode.com/) challenges. Advent of Code is an annual set of Christmas-themed programming puzzles that can be solved in any programming language.

## Running the Solutions

Each day's solution is contained in its own Python file. To run a solution:

1. Make sure you have Python installed on your system
2. Download or clone this repository
3. Run the solution for a specific day:
   ```bash
   python dayXX.py
   ```
   Replace `XX` with the two-digit day number (e.g., `python day01.py` for Day 1)
